====== Learning widgets ======

Two Eduskript widgets, **Kara** and a **quiz question**, embedded in DokuWiki with the ''learningwidget'' plugin. The widgets are static files served from [[https://bottom.ch/widgets/|bottom.ch/widgets]]; each one runs in a sandboxed iframe and is configured right here on the page. The wiki stores the answers in the browser and receives the submissions.

===== Kara =====

Both levels belong to the group ''week-1'', so their stars are stored once for the group. A solution for the first level:

<code python>
while not wall_front():
    if on_barrel():
        remove_barrel()
    move()
turn_left()
move()
</code>
